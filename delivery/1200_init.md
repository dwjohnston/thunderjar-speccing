# 1200: Init

`thunderjar init` scaffolds the `thunderjar/` configuration folder in a project, with empty `declareX` stubs.

Areas: F, A

## Artifacts

- `thunderjar init` command
- `thunderjar/` folder laid out as in [051-configuration-folder-structure.md](../spec/051-configuration-folder-structure.md), with a `.gitignore` covering `_generated/` and `.data/`
- Stub `declareX` files for each parameter kind and an example test case

## How to test

Regular test runs `thunderjar init` in an empty temp directory and asserts on the files created. A second run asserts that existing files are not overwritten.

- `bun test`

## Human interventions

None.
